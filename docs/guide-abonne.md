# Guide abonné

## Connexion et sécurité

La connexion se fait uniquement depuis le bouton **Se connecter** du portail. Après déconnexion,
le navigateur revient à la page de connexion et une nouvelle authentification est obligatoire.

## Contrat et signature

1. Ouvrir **Mon contrat** et lire le PDF.
2. Cliquer sur **Signer électroniquement**.
3. Accepter les conditions, saisir le code reçu par email, puis confirmer.
4. Télécharger le PDF signé : il contient le cachet visible et le scellement PAdES.

## Paiement

Depuis **Moyens de paiement**, sélectionner un moyen autorisé, saisir le montant et suivre le résultat.
Les transactions réussies disposent d'un reçu PDF dans **Transactions**.

## Profil

Le profil permet de consulter ses coordonnées, changer le mot de passe via Keycloak, fermer une session
ouverte et modifier les emails de résultat de paiement. Les emails de contrat et les codes de signature
restent obligatoires.
